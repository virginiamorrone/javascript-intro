Dos lenguajes para empezar a programar: en qué se parecen, en qué se diferencian y cuándo conviene cada uno.

Dos orígenes distintos

1991

Python

Creado por Guido van Rossum con una idea central: que el código sea fácil de leer, casi como pseudocódigo.

1995

JavaScript

Creado por Brendan Eich en Netscape para darle comportamiento a las páginas web dentro del navegador.

¿Dónde se usa cada uno?

JavaScript

Páginas y aplicaciones web (frontend).

Servidores con Node.js (backend).

Apps móviles y de escritorio.

Funciona en cualquier navegador sin instalar nada.

Python

Ciencia de datos e inteligencia artificial.

Automatización de tareas y scripts.

Backend web con Django o Flask.

Necesita instalar el intérprete de Python.

Ojo con el tipado

JavaScript intenta convertir tipos por su cuenta. Python prefiere avisarte con un error.

JavaScript
"5" + 1   // "51"  (une textos)
"5" - 1   // 4     (resta números)

5 == "5"  // true  (convierte)
5 === "5" // false (recomendado)
Python
"5" + 1
# TypeError: can only
# concatenate str to str

int("5") + 1  # 6

¿Cuál elegir?

Elegí JavaScript si…

Querés hacer páginas o aplicaciones web.

Te motiva ver resultados visuales rápido.

Querés empezar sin instalar nada.

Elegí Python si…

Te interesan los datos o la inteligencia artificial.

Querés automatizar tareas.

Buscás la sintaxis más amable para empezar.

Lo importante se traslada

Cambia la forma de escribirlo, pero los conceptos de fondo son los mismos en los dos lenguajes:

  • Variables
  • Tipos de datos
  • Condiciones
  • Bucles
  • Funciones
  • Listas y objetos

Aprender bien uno hace mucho más fácil aprender el otro.
